# Roast Me AI v3

Polished front-end prototype with:
- Fixed question card sizing and textarea overflow
- Exactly 3 selectable questions
- Reliable answer validation
- COOK ME activation only when photo + 3 answered questions are ready
- Responsive mobile layout
- Seven roast modes

The prototype keeps the photo in the browser. Real AI image analysis requires a secure backend; do not expose an AI API key in frontend JavaScript.
